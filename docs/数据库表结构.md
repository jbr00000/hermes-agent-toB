# 数据库表结构(Schema 参考)

> 权威来源:`server/storage/models.py`(SQLAlchemy 模型)。本文档随模型同步更新。
> 最后核对:2026-08-15(含 `tool_approvals`、`users.must_change_password`)。

## 一句话总览

**18 张表,一套 schema 两种后端**:不设 `HERMES_DATABASE_URL` 时用 SQLite(`$HERMES_HOME/hermes_tob.db`,零配置);设成 MySQL 连接串就整体切到 MySQL(Alembic 管理迁移)。两者存的数据完全相同。

## 通用约定

| 约定 | 说明 |
|---|---|
| `tenant_id` | 每张表都有。单租户部署下恒为 `default`(或 `HERMES_TENANT_ID`),是预留的隔离边界,也是几乎所有索引的第一列 |
| 时间戳 | 全部是 `Double` 类型的 Unix 秒(浮点),不是 DATETIME |
| 主键 | 多数是 `String(36)` 的 UUID;只有 `tool_events` / `audit_events` 用自增整数 |
| 用户隔离 | 没有外键约束;多用户隔离靠 repository 层查询时强制 `user_id` 过滤(属主域) |
| 迁移 | MySQL 走 Alembic(`server/migrations/`);SQLite 走 `database.py:_ADDED_COLUMNS` 补列 shim(`create_all` 不会改已有表) |

**不在数据库里的数据**:知识库上传文件本体(`$HERMES_HOME/knowledge/files/`)、JWT 密钥(`jwt.key`)、易失运行状态(Redis:取消标志/登录锁定计数/allow_all 标记)、知识库检索投影(ES/Milvus)、CLI 专用会话搜索库(`state.db`,SQLite FTS5,与本品库无关)。

## 表分组地图

```
账号与会话        users ── auth_sessions
对话             conversations ── messages ── model_runs
Agent 任务       agent_tasks ── task_runs ── task_plans
                          ├──── permission_leases(权限租约)
                          ├──── tool_approvals(命令级审批,controlled 档)
                          ├──── tool_events(工具时间线)
                          └──── artifacts(产物索引)
记忆             memory_items ←── memory_candidates
审计             audit_events
知识库           knowledge_documents ── knowledge_chunks ── knowledge_jobs
```

## 一、账号与会话

### users — 用户账号

| 列 | 类型 | 说明 |
|---|---|---|
| id | String(36) PK | UUID |
| tenant_id | String(64) | 租户,索引列 |
| username | String(128) | 与 tenant_id 联合唯一(`uq_users_tenant_username`) |
| password_hash | String(128) | bcrypt 哈希,永不出库到 API |
| role | String(16) | `superadmin` / `admin` / `user` |
| status | String(16) | `active` / `disabled`;disable 时吊销其全部 refresh 会话 |
| features | JSON, 可空 | 功能开关 `{agent, chat, knowledge, memory}`;NULL = 全开 |
| must_change_password | Boolean | 建号/管理员重置后为 true,登录后强制改密(③) |
| created_at / updated_at | Double | |

### auth_sessions — refresh 登录会话

| 列 | 类型 | 说明 |
|---|---|---|
| id | String(36) PK | |
| tenant_id / user_id | String | 索引 `idx_auth_sessions_user_expires(tenant_id, user_id, expires_at)` |
| token_hash | String(64) 唯一 | refresh token 的 SHA-256(不存原文) |
| user_agent | String(255), 可空 | |
| created_at / expires_at | Double | 默认 7 天(`HERMES_REFRESH_TOKEN_TTL`) |
| revoked_at | Double, 可空 | 登出/改密/禁用/重置密码时置位 |

### tool_approvals — controlled 档逐命令审批(① 新增)

| 列 | 类型 | 说明 |
|---|---|---|
